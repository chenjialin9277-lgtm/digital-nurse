# 首页星标宣教、数字护士播放页与音频恢复设计

**日期：** 2026-07-21
**状态：** 用户已批准，可直接实施

## 目标

1. 已标星的科室宣教在数字护士首页直接可见、可播放，不必先进入床旁宣教工作台。
2. 未标星内容通过“更多宣教”进入二级工作台查找。
3. 宣教播放时显示当前科室配置的数字护士形象；语音结束后，字幕区域切换为理解确认题，形象仍保留。
4. 修复播放离线宣教后，小智回答只有字幕没有声音的问题。

## 根因

小智在线 Opus 回答与离线宣教都通过 `flutter_pcm_player` 的同一个原生 MethodChannel 播放。离线宣教重新初始化并释放原生 `AudioTrack` 后，`AudioUtil` 仍保留“在线播放器已初始化”的 Dart 状态。小智后续音频帧被写入已失效的播放器，原生层静默丢弃，但 TTS 文本事件仍正常，因此表现为“有字幕、无声音”。

## 交互设计

### 首页

- 首页从宣教数据库加载 `enabled && favorite` 的内容，不再使用旧 `quickAnswers` 生成常用入口。
- 当前语言已发布的星标项以横向可滑动快捷按钮显示；未发布的星标项显示“该语言暂未提供”并禁用，不默认读普通话。
- 点击可用星标项后，直接创建匿名宣教会话、选中条目、打开播放页并自动开始播放，不再出现第二次“开始播放”点击。
- “更多宣教”保留二级工作台，工作台仍可查看全部内容，避免星标内容无法搜索或复播。
- 宣教库异常时，继续使用已实现的旧版应急宣教入口。

### 播放与理解确认页

- 播放前与播放中：左侧显示数字护士形象，右侧显示宣教标题、摘要、逐字字幕和播放状态。
- 播放结束：数字护士形象保留，右侧自动切换为理解确认题。
- 题目回答、重播、请护士解释、完成清屏及无操作自动清屏规则保持不变。
- 页面使用科室当前配置的形象路径；路径无效时显示默认数字护士。
- 1024×600 使用紧凑双栏，1920×1200 按比例放大，不允许字幕、题目或按钮溢出。

## 音频协调设计

- `XiaozhiService` 提供明确的在线播放暂停/恢复边界。
- 离线宣教开始前，先停止小智 PCM 播放器，使 `AudioUtil` 的 Dart 状态与原生播放器一致。
- 离线宣教完成、出错、重播中断、返回、后台清屏或超时清屏后，均重建小智 PCM 播放器。
- 小智二进制音频帧按收到顺序串行解码和写入，避免多个首帧并发重复初始化播放器。
- 在线播放恢复失败不影响宣教清屏，但通过现有错误状态向管理员提供诊断信息。

## 数据与隐私

- 星标仍是 `EducationItem.favorite`，不新增第二套快捷标记。
- 首页直达与二级工作台使用同一个 `EducationSessionController` 事件流，统计口径不变。
- 不新增姓名、住院号、床号、电话、诊断、治疗或人脸信息。

## 异常与竞态处理

- 首页加载宣教失败时不影响小智问答，显示旧版应急宣教。
- 星标项快速连点只能打开一个播放页。
- 页面退出后不得因为延迟的语音生成或事件写入而再次响起。
- 在线音频恢复使用幂等 Future，避免完成事件、页面销毁与生命周期回调重复初始化。

## 验收标准

1. 首页只显示已标星的宣教快捷按钮，点击后直接自动播放。
2. 未标星项不出现在首页，可在“更多宣教”中找到并播放。
3. 播放期间显示数字护士形象和逐字字幕，播放结束后自动显示理解题，形象不消失。
4. 播放任意离线宣教后，再按住提问，小智回答的字幕和声音均正常。
5. 普通话、粤语、英语及 1024×600、1920×1200 界面测试全部通过。
